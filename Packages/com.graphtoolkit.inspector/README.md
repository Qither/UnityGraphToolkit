# Graph Toolkit Inspector

Reusable Unity 6 Inspector extensions built with UI Toolkit.

The package provides runtime property traits and serialized collection types under
`GraphToolkit.Inspector`, plus editor drawers and controls under
`GraphToolkit.Inspector.Editor`.

The implementation is derived from PiRho Utilities. See
`THIRD-PARTY-NOTICES.md` and `LICENSE-PiRhoUtilities.md` for attribution and
license terms.
